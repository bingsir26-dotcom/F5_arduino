# F5 理科：互動系統與 Arduino 控制（F5_arduino）

學生教材網站，以 VitePress 建立，適合發佈到 GitHub Pages。

## 目前內容

- 第 0 課：程式如何控制現實世界？
- 單元一：讓裝置動起來（第 1 至第 8 課）
- Tinkercad Circuits 模擬、Arduino LED 輸出控制、除錯與「校園提示系統」作品

## 本機預覽

```powershell
npm install
npm run docs:dev
```

## GitHub Pages

建立同名 GitHub repository 後，保留 `.github/workflows/deploy-pages.yml`，並在 repository **Settings → Pages → Build and deployment** 選擇 **GitHub Actions**。
