# 第 5 課：完成一個課室環境狀態報告

## 今課可以做到甚麼？

- 把變數、`if ... else`、`for` 和 Serial Monitor 合在同一個 Arduino 程式。
- 從文字輸出看懂程式在不同資料下的判斷。
- 說出下一單元可把哪個文字結果接成硬件回應。

## 開始前：想一想

假如你是學校的資料助理，要把「課室溫度、已使用座位」整理成一個簡單報告，程式至少要做到三件事：顯示資料、作出判斷、清楚列出結果。

你認為「溫度偏高」在下一單元最適合變成甚麼硬件回應：亮燈、閃燈、蜂鳴器，還是其他？先說出你的理由。

## 今日任務：把程式結果做成小報告

![由資料到硬件回應的準備](/images/status-report-to-hardware.svg)

本課仍先把結果印出來。這不是少做一步，而是把將來硬件要做的事情先寫清楚：當甚麼條件出現，裝置應該回應甚麼。

## 跟著做：三次課室狀態報告

```cpp
int temperature = 28;
int totalSeats = 28;
int usedSeats = 26;
int emptySeats = totalSeats - usedSeats;

void setup() {
  Serial.begin(9600);

  for (int report = 1; report <= 3; report++) {
    Serial.print("第 ");
    Serial.print(report);
    Serial.println(" 次課室報告");

    Serial.print("空位數：");
    Serial.println(emptySeats);

    if (temperature > 26) {
      Serial.println("狀態：溫度偏高，建議通風");
    } else {
      Serial.println("狀態：溫度合適");
    }

    Serial.println("---");
  }
}

void loop() {
}
```

**預期輸出：**

```text
第 1 次課室報告
空位數：2
狀態：溫度偏高，建議通風
---
第 2 次課室報告
空位數：2
狀態：溫度偏高，建議通風
---
第 3 次課室報告
空位數：2
狀態：溫度偏高，建議通風
---
```

## 把程式拆開看

- 最上方的 `int ...`：保存本次報告用的資料。
- `emptySeats = totalSeats - usedSeats`：根據資料計算空位。
- `for`：要求程式列出三次報告，方便檢查重複輸出。
- `if ... else`：根據溫度選擇不同的文字結果。
- `Serial.println("---");`：用分隔線讓人容易看出每一次報告的範圍。

## 再試一次：只改資料，觀察規則

把：

```cpp
int temperature = 28;
int usedSeats = 26;
```

改成：

```cpp
int temperature = 24;
int usedSeats = 20;
```

**預期改變：** 空位數變成 8；狀態改成「溫度合適」。程式的判斷規則和循環結構不用重寫。

## 易錯位

| ✕ 錯誤 | 原因 | 修正方法 |
| --- | --- | --- |
| 在 `if` 外面先寫死某一個狀態文字 | 無論資料怎樣變，結果都不會改 | 把不同結果分別放入 `if` 與 `else` |
| `emptySeats` 在計算前已經使用 | 程式未有正確答案 | 先建立與計算，再顯示 |
| 把 `for` 的大括號放錯 | 可能只有第一行重複 | 所有報告內容要放入 `for { ... }` |
| 把 `temperature > 26` 寫成 `temperature = 26` | 變成放入資料，並非比較 | 比較用 `>`、`<`、`==` 等符號 |

## 本課小結

- 一個實用的 Arduino 程式可先用文字輸出檢查資料、規則和重複結果。
- 變數保存資料；`if` 作判斷；`for` 安排固定次數工作。
