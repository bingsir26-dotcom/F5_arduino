# 第 5 課：把重複工作交給一個函式

## 今課可以做到甚麼？

- 把一組重複顯示的指令放進自己命名的函式。
- 用函式名稱讓程式更容易閱讀與修改。
- 用簡短註解說明程式的重要部分。

## 開始前：想一想

如果每次檢查課室狀態，都要重複寫十多行 `Serial.print()`；下次想改一個標題，要改幾個地方？我們可以替「一整組工作」取一個名字。

## 把一組工作命名

~~~cpp
void printReport() {
  Serial.println("--- 課室狀態 ---");
  Serial.println("正在檢查資料");
}
~~~

`void printReport()` 是自訂函式。花括號內是它要做的工作；之後寫 `printReport();`，Arduino 就會執行這些指令。 `//` 後面的文字是註解，只給人閱讀。

## 跟著做：印出兩次完整報告

~~~cpp
int reportNumber = 1;

void printReport() {
  // 顯示一次狀態報告的標題
  Serial.print("第 ");
  Serial.print(reportNumber);
  Serial.println(" 次檢查完成");
}

void setup() {
  Serial.begin(9600);
  printReport();
  reportNumber = 2;
  printReport();
}

void loop() {
}
~~~

**預期輸出：**

~~~text
第 1 次檢查完成
第 2 次檢查完成
~~~

## 再試一次：只改一處，兩次都更新

把函式內的「次檢查完成」改成「次課室資料已更新」；兩次輸出都會一起改變，因為它們都使用同一個 `printReport()`。

## 易錯位

| ✕ 錯誤 | 原因 | 修正方法 |
| --- | --- | --- |
| 寫 `printReport`，最後沒有 `()` | 不會當作函式呼叫 | 寫成 `printReport();` |
| 函式名稱前後大小寫不同 | 是不同名稱 | 全程使用同一個名稱 |
| 把函式放進 `setup()` | 不可在函式內再宣告函式 | 放在 `setup()` 外 |
| 註解沒有 `//` | Arduino 會把它當程式碼 | 單行註解前加 `//` |

## 你來做

- **基礎題**：建立 `showName()`，顯示自己的名字。
- **標準題**：建立 `showStatus()`，在 `setup()` 呼叫兩次。
- **挑戰題**：把第 4 課的倒數標題放入一個函式，加入一行註解。

## 本課小結

- 函式把一組工作取名，方便重複使用。
- 函式內改一次，所有呼叫它的位置都會使用新版本。
- 註解用來說明重要意圖，不會被 Arduino 執行。
