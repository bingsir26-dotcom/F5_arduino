# 單元一：先讓程式說話

## 單元最後會完成甚麼？

你會在 **Tinkercad Circuits** 的 Arduino 模擬中，利用 **Serial Monitor（序列監視器）** 顯示程式結果，完成一個「課室環境狀態報告」小程式。它會把一組數值資料顯示出來、按條件作判斷，並重複列出指定次數的結果。

![單元一程式學習地圖](/images/programming-basics-roadmap.svg)

## 為甚麼先不接 LED？

Arduino 程式一開始同時要面對兩件事：**程式邏輯**和**電路接線**。如果燈不亮，初學者很難判斷到底是程式寫錯，還是電路沒有接好。

所以這個單元先把結果印在螢幕上。你可以先清楚看到每一次計算、判斷和重複的結果；到下一單元才把**同一套邏輯**交給 LED、蜂鳴器和其他硬件執行。

## 五課地圖

| 課次 | 要解答的問題 | 核心成果 |
| --- | --- | --- |
| 第 1 課 | Arduino 程式從哪裡開始？ | 在 Serial Monitor 顯示第一句結果 |
| 第 2 課 | 程式怎樣記住和計算資料？ | 用變數顯示溫度、座位數和計算結果 |
| 第 3 課 | 程式怎樣按情況作決定？ | 用 `if ... else` 顯示不同提示 |
| 第 4 課 | 程式怎樣有規律地重複？ | 用 `for` 重複列出倒數或檢查結果 |
| 第 5 課 | 怎樣把幾種語法合成一個程式？ | 課室環境狀態報告 |

## 最後小作品：課室環境狀態報告

你會自行設定一組**練習數值**，例如課室溫度、使用中的座位數或噪音等級。程式需要：

- [ ] 用至少兩個變數保存資料。
- [ ] 用 `Serial.print()` 或 `Serial.println()` 清楚顯示資料。
- [ ] 用 `if ... else` 顯示一個有根據的狀態提示。
- [ ] 用 `for` 至少重複顯示三次結果。
- [ ] 寫出一至兩句話，說明下一單元可把哪一個文字提示改為 LED 或蜂鳴器回應。

::: tip 上課操作
在 Tinkercad Circuits 建立新 Circuit 後，只需放入一塊 **Arduino Uno**；本單元暫時不用連接 LED 或導線。切換至 **Code → Text**，在開始模擬後開啟 **Serial Monitor** 查看輸出。
:::
