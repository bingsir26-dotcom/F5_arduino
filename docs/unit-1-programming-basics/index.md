# 單元一：先讓程式說話

## 單元最後會完成甚麼？

你會在 **Tinkercad Circuits** 的 Arduino 模擬中，只使用 Arduino Uno 與 **Serial Monitor（序列監視器）**，完成「課室環境狀態報告」。程式會讀取資料、作出判斷、重複顯示結果；你可以先在文字輸出中確認每一條規則是否正確。

![單元一程式學習地圖](/images/programming-basics-roadmap.svg)

## 為甚麼先不接 LED？

Arduino 程式同時有**程式邏輯**和**電路接線**兩類問題。初學者看見燈不亮時，很難立即知道是哪一類問題。因此先把結果印在螢幕：看清楚計算、判斷與重複的結果後，再把**同一套規則**交給 LED 等硬件。

## 七課地圖

| 課次 | 要解答的問題 | 核心成果 |
| --- | --- | --- |
| 第 1 課 | Arduino 程式從哪裡開始？ | 在 Serial Monitor 顯示第一句結果 |
| 第 2 課 | 程式怎樣記住和計算資料？ | 用 int、float 顯示座位和溫度資料 |
| 第 3 課 | 程式怎樣按多個情況作決定？ | 用 if ... else、bool 顯示不同提示 |
| 第 4 課 | 程式怎樣有規律地重複？ | 用 for 重複列出倒數或檢查結果 |
| 第 5 課 | 怎樣把重複的工作整理好？ | 用自訂函式印出一段完整報告 |
| 第 6 課 | 程式出現錯誤時怎樣找？ | 用檢查步驟找出語法與邏輯問題 |
| 第 7 課 | 怎樣把幾種工具合成一個程式？ | 課室環境狀態報告 |

## 本單元作品：課室環境狀態報告

作品先把**系統規則**寫清楚，例如：

~~~text
課室溫度：28.5°C
使用座位：26 / 28
狀態：課室有人，而且溫度偏高，建議通風
~~~

完成時，程式至少要有：兩個以上有意義的變數、一個小數資料、一條 if ... else 規則、一次 for、一個自訂函式，以及一張能看見程式與 Serial Monitor 結果的截圖。到單元二，這個文字結果會逐步轉換成 LED 燈號。
