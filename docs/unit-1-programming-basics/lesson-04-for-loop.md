# 第 4 課：用循環重複有規律的工作

## 今課可以做到甚麼？

- 分辨 Arduino 的 `loop()` 與 `for` 循環各自的用途。
- 用 `for` 指定重複的次數。
- 把每次重複的結果顯示在 Serial Monitor。

## 開始前：想一想

如果你要在螢幕上列出「第 1 次檢查」到「第 5 次檢查」，你會把五行 `Serial.println()` 手動寫出來，還是叫程式自己重複？

先猜一猜：下面的計數器由 `1` 開始、每次加 `1`，直到 `5` 為止，總共會顯示多少行？

## 兩種「重複」

![loop 和 for 的分工](/images/loop-and-for.svg)

- `loop()`：Arduino 程式本身會不停重複執行的地方；適合日後不斷讀取感測器、更新燈號。
- `for (...)`：你指定「由哪裡開始、何時停止、每次怎樣改變」的一段重複工作；適合倒數、逐項檢查或固定次數測試。

## 跟著做：列出五次檢查

```cpp
void setup() {
  Serial.begin(9600);

  for (int check = 1; check <= 5; check++) {
    Serial.print("第 ");
    Serial.print(check);
    Serial.println(" 次檢查完成");
  }
}

void loop() {
}
```

**預期輸出：**

```text
第 1 次檢查完成
第 2 次檢查完成
第 3 次檢查完成
第 4 次檢查完成
第 5 次檢查完成
```

逐段看：

- `int check = 1`：先建立計數用的變數，從 1 開始。
- `check <= 5`：只要 `check` 小於或等於 5，就繼續重複。
- `check++`：每做完一次，把 `check` 加 1。
- 大括號內的三行：每次重複都會執行一次。

## 再試一次：改成倒數

只改 `for` 的第一行和輸出文字：

```cpp
for (int second = 3; second >= 1; second--) {
  Serial.print(second);
  Serial.println("...");
}
Serial.println("開始！");
```

**預期輸出：**

```text
3...
2...
1...
開始！
```

這種倒數邏輯，日後可用在活動開始提示、交通燈轉換前的提醒，或硬件測試。

## 易錯位

| ✕ 錯誤 | 原因 | 修正方法 |
| --- | --- | --- |
| `check < 5` | 最後只會到 4 | 要包括 5，使用 `check <= 5` |
| 忘記 `check++` | 計數不會增加，循環可能不停執行 | 在第三部分加上 `check++` |
| `second++` 用在倒數 | 數字愈來愈大，無法到達停止條件 | 倒數使用 `second--` |
| 忘記大括號 | 很容易只有第一行被重複 | 需要重複的指令全部放入 `{ ... }` |

## 你來做

- **基礎題**：用 `for` 顯示 1 到 3 的測試編號。
- **標準題**：由 10 倒數至 1，再顯示「活動開始」。
- **挑戰題**：將五次檢查改成每次同時顯示「正在檢查座位」，並說出將來可用甚麼硬件取代這一句文字。

## 本課小結

- `loop()` 是 Arduino 整個程式會不斷重複的區域。
- `for` 用來完成固定次數或有規律的重複。
- 循環要清楚寫出開始值、停止條件和每次變化。
