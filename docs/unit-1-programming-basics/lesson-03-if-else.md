# 第 3 課：用 if 讓程式按情況決定

## 今課可以做到甚麼？

- 用 `if` 檢查一個條件是否成立。
- 用 `else` 為另一種情況準備結果。
- 在 Serial Monitor 顯示有根據的狀態提示。

## 開始前：想一想

同一句「請開窗」不應該在每一個情況都出現。如果課室溫度已經很低，程式應該顯示不同建議。

假設「溫度高於 26°C 就提示開窗」，當溫度是 28 時會出現甚麼？當溫度是 24 時呢？

## 讓程式檢查條件

![條件判斷的兩種結果](/images/if-else-condition.svg)

`if` 的括號內放一個問題，例如 `temperature > 26`。如果答案是「是」，程式執行第一組大括號內的指令；否則就執行 `else` 的部分。

常見比較符號：

| 寫法 | 意思 |
| --- | --- |
| `>` | 大於 |
| `<` | 小於 |
| `>=` | 大於或等於 |
| `<=` | 小於或等於 |
| `==` | 是否相等 |

## 跟著做：顯示課室通風提示

```cpp
int temperature = 28;

void setup() {
  Serial.begin(9600);

  if (temperature > 26) {
    Serial.println("溫度偏高：建議通風");
  } else {
    Serial.println("溫度合適：維持目前狀態");
  }
}

void loop() {
}
```

**預期輸出：**

```text
溫度偏高：建議通風
```

逐行看：

- `if (temperature > 26)`：問「溫度是否高於 26？」
- `{ ... }`：條件成立時執行的指令範圍。
- `else`：條件不成立時，改做另一件事。
- `Serial.println(...)`：將最後判斷結果顯示給我們看。

## 再試一次：改一個數字，比較結果

只把：

```cpp
int temperature = 28;
```

改成：

```cpp
int temperature = 24;
```

**預期輸出：**

```text
溫度合適：維持目前狀態
```

程式沒有改規則，只是資料變了，所以輸出的提示改變。之後接上硬件時，這兩個文字結果就可以分別對應到不同燈號或蜂鳴器提示。

## 易錯位

| ✕ 錯誤 | 原因 | 修正方法 |
| --- | --- | --- |
| `if temperature > 26` | `if` 條件需要括號 | 寫成 `if (temperature > 26)` |
| 用 `=` 比較是否相等 | `=` 是放入資料，不是比較 | 比較相等要用 `==` |
| 忘記 `{` 或 `}` | 程式不清楚哪些指令屬於條件 | 成對檢查每組大括號 |
| 把 `else` 寫成 `Else` | 程式區分大小寫 | 用小寫 `else` |

## 你來做

- **基礎題**：設定 `score`；若分數 `>= 50` 顯示「合格」，否則顯示「需要再練習」。
- **標準題**：設定 `emptySeats`；若空位 `> 0` 顯示「仍有空位」，否則顯示「已滿」。
- **挑戰題**：把溫度標準由 26 改為你認為合適的數值，並在註解中寫下理由。

## 本課小結

- `if` 讓程式按條件選擇做法。
- `else` 處理條件不成立的另一種情況。
- 先在螢幕看清文字結果，之後才容易把結果接到硬件回應。
