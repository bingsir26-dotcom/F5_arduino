# 單元一：讓裝置動起來

## 單元最後會完成甚麼？

你會在 **Tinkercad Circuits** 完成一個可運行的「校園提示系統」：用 Arduino 控制至少三盞 LED，讓燈號按你設計的規則改變，並交代它服務的校園情境與測試結果。

![單元一課程地圖](/images/unit-one-roadmap.svg)

## 專題情境：校園提示系統

校園有不少需要清楚提示的時刻：圖書館是否需要安靜、實驗室能否進入、活動是否即將開始、走廊是否正在使用。燈號不是裝飾；它要讓人一眼看懂現時狀態。

本單元只用**虛構校園情境**作練習。重點不是模仿真正的安全設備，而是學習把「狀態與規則」實作成安全、可測試的電路和程式。

## 八課地圖

| 課次 | 要解答的問題 | 核心成果 |
| --- | --- | --- |
| 第 1 課 | 怎樣開始一個電路模擬？ | 第一個可開始／停止的 Tinkercad 專案 |
| 第 2 課 | LED 怎樣才會安全亮起？ | 一個完整、含電阻與 GND 的回路 |
| 第 3 課 | Arduino 怎樣控制燈？ | 用 `pinMode()`、`digitalWrite()` 亮燈與熄燈 |
| 第 4 課 | 程式怎樣安排時間？ | 按節奏閃爍的 LED |
| 第 5 課 | 三盞燈如何表示狀態？ | 一個交通燈狀態系統 |
| 第 6 課 | 怎樣讓程式易讀、易改？ | 以名稱代替魔法數字的程式 |
| 第 7 課 | 裝置不動時怎樣找問題？ | 一次有步驟的除錯紀錄 |
| 第 8 課 | 怎樣把技術用在情境？ | 校園提示系統專題 |

## 最後作品的完成標準

- [ ] Tinkercad Circuits 模擬含有 Arduino Uno、至少三盞 LED 和每盞 LED 對應的電阻。
- [ ] 每盞 LED 都有清楚、完整的回路與 GND 路徑。
- [ ] 程式使用有意義的腳位名稱，例如 `redLed`、`quietLed`。
- [ ] 燈號有清楚的狀態規則，不只是隨意閃爍。
- [ ] 交付一張模擬截圖或 Tinkercad 分享連結。
- [ ] 用 80 至 120 字交代情境、燈號規則和一次測試／修正。

## 先準備甚麼？

- 可上網的電腦與瀏覽器。
- Tinkercad 帳戶；如由學校統一管理，可按教師提供的班級方式進入。
- 建議開啟 [Tinkercad Circuits](https://www.tinkercad.com/circuits) 後，先嘗試建立一個新 Circuit。

::: warning 安全提醒
本單元使用**線上模擬**，不需要接觸真實電源或焊接。日後使用實體 Arduino 時，必須按教師指示接線，切勿把 LED 直接長時間接在電源兩端。
:::
