# 第 2 課：讓 LED 安全亮起來

## 今課可以做到甚麼？

- 接出一個讓 LED 穩定亮起的完整回路。
- 說出 LED、電阻和 GND 各自的作用。
- 看懂 LED 方向與電阻為何不能省略。

## 開始前：想一想

把水從水龍頭流到水桶，需要有去路；電路也一樣。若只有一端接上，電流不能完成循環，LED 不會正常亮起。

你認為 LED 直接連在電源兩端，會比先經過電阻更亮，還是更容易出問題？

## 新概念：完整回路與保護

![Arduino、電阻、LED 與 GND 的完整回路](/images/led-circuit.svg)

LED 要亮，電流要由一端流過 LED，最後回到 GND，形成完整回路。**電阻**不是用來令 LED 變暗的裝飾，而是限制電流，讓 LED 在合理範圍內工作。

- LED 較長的一腳通常是正極（anode）。
- 較短的一腳通常是負極（cathode）。
- 在 Tinkercad 可先點選 LED，查看它的正負極標示。

## 跟著做：用 5V 亮起 LED

1. 在 Arduino 的 **5V** 腳位接一條導線到電阻的一端。
2. 把電阻另一端接到 LED 的正極。
3. 把 LED 負極接回 Arduino 的 **GND**。
4. 把電阻設為 `220 Ω` 或 `330 Ω`。
5. 開始模擬，確認 LED 亮起。

這一課使用 5V 只是為了先理解電路。第 3 課會把 LED 改接到數位腳位，交由程式控制。

## 再試一次：改變電阻值

把電阻由 `220 Ω` 改成 `1 kΩ`，再開始模擬。

你應該會看到 LED 仍然亮起，但較暗。這表示電阻限制了流過 LED 的電流；它不是可有可無的零件。

## 易錯位

| ✕ 錯誤 | 為甚麼 | 修正方法 |
| --- | --- | --- |
| LED 直接接 5V 與 GND，沒有電阻 | 電流可能過大 | 在 LED 同一回路串聯一個電阻 |
| LED 兩腳接反 | LED 有方向 | 交換 LED 方向，再測試 |
| LED 只接 5V，沒有接 GND | 回路沒有完成 | 把另一端接回 GND |
| 電阻接在旁邊，沒有串在回路中 | 電流沒有經過電阻 | 檢查路徑是否為 5V → 電阻 → LED → GND |

## 你來做

- **基礎題**：接出一盞固定亮起的紅色 LED。
- **標準題**：把它改成黃色 LED，並比較 `220 Ω` 與 `1 kΩ` 的效果。
- **挑戰題**：不用查看筆記，向同學指出回路中的 GND 在哪裡。

## 本課小結

- LED 必須接在完整回路內才會亮。
- LED 有方向；接反通常不會亮。
- 電阻限制電流，保護 LED。
