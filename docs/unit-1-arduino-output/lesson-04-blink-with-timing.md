# 第 4 課：讓燈按節奏工作

## 今課可以做到甚麼？

- 用 `delay()` 控制 LED 保持亮起或熄滅多久。
- 知道 `loop()` 會重複執行。
- 寫出一盞按指定節奏閃爍的提示燈。

## 開始前：想一想

一盞只會亮或熄的燈可以表達狀態；一盞按節奏閃爍的燈，還可以表達「請注意」、「正在等候」或「即將開始」。

如果燈亮 1 秒、熄 2 秒，這個規則在程式中要怎樣寫？

## 新概念：時間與重複

`delay(1000)` 表示程式暫停約 1000 毫秒，即 1 秒。放在 `loop()` 裡的程式，完成一次後會回到開頭再做一次。

## 跟著做：每秒閃一次

```cpp
void setup() {
  pinMode(8, OUTPUT);
}

void loop() {
  digitalWrite(8, HIGH);
  delay(1000);
  digitalWrite(8, LOW);
  delay(1000);
}
```

**預期效果：** LED 亮約 1 秒、熄約 1 秒，然後一直重複。

程式順序很重要：先亮燈，等一段時間；再熄燈，等一段時間；`loop()` 再回到第一行。

## 再試一次：改成「短亮、長熄」

只改兩個數字：

```cpp
  delay(300);   // 亮 0.3 秒
  digitalWrite(8, LOW);
  delay(1700);  // 熄 1.7 秒
```

這會形成較像提示燈的節奏。請先用眼睛觀察，再寫下你覺得哪個節奏較適合「活動即將開始」。

## 易錯位

| ✕ 錯誤 | 為甚麼 | 修正方法 |
| --- | --- | --- |
| 把 `1000` 當成 1000 秒 | `delay()` 用毫秒 | 記住 1000 毫秒 = 1 秒 |
| 只寫亮燈，沒有熄燈 | 狀態沒有改變 | 加入 `digitalWrite(8, LOW)` |
| 把閃燈指令放進 `setup()` | `setup()` 只執行一次 | 重複的規則放在 `loop()` |
| 少了分號 `;` | C++ 指令結尾需要分號 | 每個指令句尾加上 `;` |

## 你來做

- **基礎題**：讓 LED 每 0.5 秒閃一次。
- **標準題**：設計亮 0.2 秒、熄 1.8 秒的節奏。
- **挑戰題**：為你的節奏命名，例如「安靜提示」或「準備開始」，並說明原因。

## 本課小結

- `delay()` 用毫秒安排等待時間。
- `loop()` 內的指令會不斷重複。
- 改變亮與熄的時間，就能改變燈號表達的感覺。
