## 本單元會用到的網站

- [Tinkercad Circuits](https://www.tinkercad.com/circuits)：線上建立 Arduino 電路模擬與撰寫程式。

## 學生交付前檢查

![除錯檢查圖](/images/debug-check.svg)

1. 模擬是否可以開始，而沒有出現錯誤訊息？
2. 每盞 LED 是否都有電阻，而且方向正確？
3. 程式中的腳位號碼，是否與接線一致？
4. 你的燈號規則能否用一句話讓別人明白？
5. 有沒有留下至少一項測試或修正紀錄？

## 名詞小字典

| 名詞 | 本課先怎樣理解 |
| --- | --- |
| Arduino Uno | 可以按程式控制電子元件的微控制板 |
| 腳位（pin） | Arduino 與外面電路連接的位置 |
| GND | 電路回到共同參考點的路徑 |
| LED | 會發光的二極管；接反通常不會亮 |
| 電阻 | 限制電流，保護 LED |
| 模擬 | 先在螢幕中測試電路和程式 |
