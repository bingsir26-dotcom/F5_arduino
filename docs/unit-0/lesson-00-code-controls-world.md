# 第 0 課：程式如何控制現實世界？

## 今課可以做到甚麼？

- 說出一個互動系統怎樣「感知、判斷、回應」。
- 從自動門、交通燈或校園設備中找出輸入、規則和輸出。
- 知道第一單元會先完成系統的「回應」部分。

## 開始前：想一想

自動門看見有人靠近才打開；交通燈依照時間改變；校園鐘在指定時間響起。它們不是「自己知道要做甚麼」，而是按照已寫好的規則工作。

如果要設計一盞「實驗進行中」提示燈，你覺得它要知道甚麼？又應該怎樣回應？

## 一個互動系統的三件事

![感知、判斷、回應的系統圖](/images/input-process-output.svg)

- **感知**：收到現實世界的資料，例如按鈕被按下、光線變暗、距離變近。
- **判斷**：程式按規則決定下一步，例如「如果光線不足，就開燈」。
- **回應**：讓燈、蜂鳴器、螢幕或馬達做出動作。

第一單元暫時不讓裝置「感知」，而是先把回應做好：安全地接 LED、用程式控制它、讓它按規則改變。

## 跟著看：交通燈的規則

交通燈不需要每秒重新猜答案。它只是在不同狀態之間切換：綠燈亮一段時間，黃燈亮短一段時間，最後紅燈亮，然後重複。

![三燈狀態示意](/images/traffic-light-states.svg)

這正是你在第 5 課會寫的程式：先定義每一種狀態，再安排它們的順序與時間。

## 你來做

1. 選一件校園內會「自動回應」的設備。
2. 用三句話寫下：它感知甚麼？按甚麼規則判斷？最後怎樣回應？
3. 如果沒有感測器，它仍可以按甚麼規則工作？

## 本課小結

- 互動系統把現實世界的訊號，變成裝置的動作。
- 一個系統通常包含感知、判斷和回應。
- 先把輸出控制做好，之後再加入感測輸入，會較容易找錯。
