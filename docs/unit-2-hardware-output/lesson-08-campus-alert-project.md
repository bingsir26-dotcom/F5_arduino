# 第 13 課：設計一個校園提示系統

## 今課可以做到甚麼？

- 把一個校園情境轉成清楚的燈號規則。
- 用 Arduino 和至少三盞 LED 完成可運行的模擬作品。
- 用截圖、程式和測試紀錄向別人解釋作品。

## 開始前：想一想

一個好提示系統，不是「燈越多越厲害」，而是人看到它後，知道應該怎樣做。你的作品想幫誰減少哪一個誤會或等待？

## 新概念：由情境走到作品

![校園提示系統作品流程](/images/project-brief.svg)

作品可以按以下次序完成：

1. **情境**：例如實驗室正在進行危險操作，門外需要有清楚提示。
2. **規則**：紅燈代表暫停進入，黃燈代表準備，綠燈代表可以進入。
3. **實作**：接好 Arduino、電阻、LED 和 GND，再寫控制程式。
4. **測試**：逐一檢查每個狀態，記錄曾經出現的問題。
5. **展示**：用一張截圖和一段文字，讓沒有學過 Arduino 的人也看懂。

## 跟著做：作品最低版本

可以先由這個版本開始，再改成自己的情境：

```cpp
const int readyLed = 8;
const int waitLed = 9;
const int stopLed = 10;

void setup() {
  pinMode(readyLed, OUTPUT);
  pinMode(waitLed, OUTPUT);
  pinMode(stopLed, OUTPUT);
}

void loop() {
  digitalWrite(readyLed, HIGH);
  digitalWrite(waitLed, LOW);
  digitalWrite(stopLed, LOW);
  delay(3000);

  digitalWrite(readyLed, LOW);
  digitalWrite(waitLed, HIGH);
  digitalWrite(stopLed, LOW);
  delay(1000);

  digitalWrite(readyLed, LOW);
  digitalWrite(waitLed, LOW);
  digitalWrite(stopLed, HIGH);
  delay(3000);
}
```

這只是「能運行的起點」，不是最後答案。你要改變的是情境、名稱、燈號意思和時間安排。

## 再試一次：改成你的校園情境

選擇一個情境，完成以下句子：

> 這個系統是給 ______ 看，想提示他們 ______。
> ______ 燈代表 ______；______ 燈代表 ______；______ 燈代表 ______。
> 我測試後發現 ______，所以我把 ______ 改成 ______。

## 易錯位

| ✕ 錯誤 | 為甚麼 | 修正方法 |
| --- | --- | --- |
| 三盞燈有亮，但沒有人看得懂 | 沒有設計狀態意思 | 為每盞燈／每個狀態寫一句人話 |
| 程式名稱仍是 `redLed`，但情境已改成圖書館 | 名稱和作品語意脫節 | 改成 `quietLed`、`pleaseWaitLed` 等 |
| 只交程式碼，沒有模擬畫面 | 別人無法確認作品真的運行 | 附上清楚的 Tinkercad 截圖或連結 |
| 作品看似成功，但沒有測試紀錄 | 不知道是否真的逐一檢查 | 記錄至少一次問題、檢查和結果 |

## 你來做

- **基礎題**：完成一個三燈校園提示系統。
- **標準題**：讓三種狀態的時間符合你的情境，並寫出原因。
- **挑戰題**：加一個「全熄／待機」狀態，說明它何時出現。

## 本課小結

- 作品先從「幫誰解決甚麼提示問題」開始。
- 燈號是狀態的視覺表示；程式把狀態變成實際輸出。
- 一個可展示作品要同時有情境、電路、程式、測試和說明。
